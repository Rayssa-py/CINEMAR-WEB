## 📌 Sobre o Projeto

O **CINEMAR** é uma página web desenvolvida para divulgar a exibição de produções cinematográficas e curtas-metragens criados por estudantes do **Instituto Federal do Ceará (IFCE)**.

O projeto foi construído utilizando conceitos práticos de estruturação semântica com **HTML5** e estilização externa via **CSS3**, proporcionando uma navegação fluida por meio de links internos e seções bem definidas.

## 🚀 Estrutura do Código (`index.html`)

A página é dividida nas seguintes seções:

- **Cabeçalho (`<header id="inicio">`):**
  - Título do evento e menu de navegação (`.menu`) com links de ancoragem para `#inicio`, `#destaques`, `#programacao` e `#contato`.

- **Seção Apresentação (`.apresentacao`):**
  - Texto introdutório sobre a mostra de filmes e banner principal com imagem ilustrativa.

- **Seção Destaques (`#destaques`):**
  - Grade de cartões (`.cards` > `.card`) apresentando os filmes em exibição, como *Esfrie*, *Ato Pós Tomo*, *Caminho do Altar*, *Cena Oculta* e sessões especiais.

- **Seção Programação (`#programacao`):**
  - Bloco de informações gerais (`.informacoes`): Data & Horário, Local (Auditório) e Informações de Entrada.
  - Tabela de horários (`<table>`): Organização cronológica das exibições, sessões e debate com os diretores.

- **Seção Contato (`#contato`):**
  - Canais de comunicação do evento (E-mail, Instagram e Telefone).

- **Rodapé e Navegação (`<footer>` & `.voltar-topo`):**
  - Direitos autorais, identificação dos desenvolvedores e botão de atalho para retornar ao topo da página.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica com tags `<header>`, `<main>`, `<section>`, `<nav>`, `<table>` e `<footer>`.
- **CSS3:** Estilização externa vinculada pelo arquivo `style.css`.
